# Lessons for KOML

Scope approval arithmetic is straightforward only after defining the unit of comparison: one independent engagement snapshot. A stream of overlapping task records would inflate exposure, so consolidation is an explicit operating requirement.

The assumption validated by synthetic evidence is that exact approvals, requested totals and explicit rates permit deterministic detection with reconciled hypothetical exposure. The assumption that this returns useful time or earns revenue remains untested. Deliverable names and minutes cannot establish contractual meaning or actual loss.

Operating rule for future builds: define the unit of aggregation and provenance before generating fixtures, and keep independently calculated expectations separate from production computations. A passing fixture is technical evidence, not measured user value.
